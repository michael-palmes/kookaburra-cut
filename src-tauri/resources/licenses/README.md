# Kookaburra Cut licences

Kookaburra Cut is free and open source, MIT OR Apache-2.0 (`LICENSE-MIT`, `LICENSE-APACHE`).
`NOTICE.md` covers the bundled assets, the device models and the ffmpeg sidecar.

- `THIRD-PARTY-NOTICES.txt`: every npm package and Rust crate built into the app, with its licence text.
- `sidecar/`: the GPL licences of the bundled ffmpeg, x264 and x265, copied from their pinned sources.
  Each release attaches those sources.
- `fonts/`: the SIL Open Font License and each family's copyright line.
- `shaders/`: the backgrounds adapted from paper-design/shaders (Apache-2.0).
- `beat-this/`: the beat tracking model's MIT licence.
