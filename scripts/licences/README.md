# Licence texts

`spdx/`: the standard texts from spdx/license-list-data v3.27.0, used in `THIRD-PARTY-NOTICES.txt`
for a package that ships no licence file of its own. `beat-this-rs-LICENSE`: beat-this-rs's LICENSE
at the commit `scripts/setup-models.sh` pins. `scripts/licence-notices.mjs` assembles both into the app.
