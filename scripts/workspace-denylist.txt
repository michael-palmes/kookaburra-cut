# Shapes of past workspace leaks, one JavaScript regex per line, matched case-insensitively
# against every line a branch adds (scripts/workspace-names.mjs). Neutral by construction:
# never a real project, product, client or person's name. Add a shape, not a name.

# A real home folder in a path; docs and tests write /Users/x instead.
/Users/(?!x/)[A-Za-z0-9._-]+/

# A concrete project folder under the workspace; write a placeholder such as <slug> or product-tour.
~/Kookaburra Cut/(?!(_autorun|_bridge|brands|themes|fonts|gradients|export-presets|presets|screenshots|objects|templates|product-tour|launch-2026|<)\b)[A-Za-z0-9][A-Za-z0-9._-]*[0-9][A-Za-z0-9._-]*

# A date-stamped project slug, the app's default project name shape, outside its own tests.
\b20[0-9]{2}-[01][0-9]-[0-3][0-9]-[a-z][a-z0-9]*(-[a-z0-9]+)*\b
